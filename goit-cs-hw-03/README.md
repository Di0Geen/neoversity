# Домашнє завдання goit-cs-hw-03

Домашня робота Вступ до вивчення систем управління базами даних

## Завдання 1

Створено базу даних системи управління завданнями з таблицями:

- `users` — користувачі системи;
- `status` — статуси завдань;
- `tasks` — завдання користувачів.

Між таблицями налаштовано зовнішні ключі. При видаленні користувача його завдання автоматично видаляються завдяки `ON DELETE CASCADE`.

Поля `users.email` і `status.name` мають обмеження `UNIQUE`.

Скрипт `seed.py` заповнює таблиці тестовими даними з використанням бібліотеки Faker.

У файлі `queries.sql` реалізовано 14 SQL-запитів для вибірки, додавання, оновлення, видалення та групування даних.

## Завдання 2

Створено Python-застосунок для виконання CRUD-операцій із колекцією котів у MongoDB.

Програма дозволяє:

- додати нового кота;
- переглянути всіх котів;
- знайти кота за ім'ям;
- оновити вік кота;
- додати нову характеристику;
- видалити кота за ім'ям;
- видалити всі записи з колекції.

Передбачено обробку помилок підключення та неправильного введення віку.

## Запуск проєкту

Створити й активувати віртуальне середовище:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Встановити залежності:

```bash
pip install -r requirements.txt
```

Запустити PostgreSQL і MongoDB:

```bash
docker compose up -d
```

### Запуск завдання 1

Створити таблиці:

```bash
python task1/create_tables.py
```

Заповнити таблиці тестовими даними:

```bash
python task1/seed.py
```

Виконати SQL-запити:

```bash
docker exec -i goit-cs-postgres psql -v ON_ERROR_STOP=1 -U postgres -d task_manager < task1/queries.sql
```

### Запуск завдання 2

```bash
python task2/main.py
```

Зупинити контейнери:

```bash
docker compose down
```
