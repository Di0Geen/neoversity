# goit-algo-hw-05

Домашнє завдання №5 з алгоритмів та структур даних.

Мета роботи — реалізувати алгоритми пошуку підрядка, порівняти час їх виконання та визначити найефективніший варіант для двох текстів.

## Структура проєкту

```text
goit-algo-hw-05/
├── .gitignore
├── README.md
├── task1.py
├── стаття_1.txt
└── стаття_2.txt
```

## Реалізація

У файлі `task1.py` реалізовано три алгоритми:

* Boyer-Moore — виконує пошук за допомогою таблиці зсувів;
* Knuth-Morris-Pratt — використовує таблицю префіксів;
* Rabin-Karp — порівнює хеші підрядка та частин тексту.

Для перевірки використано два текстові файли. У кожній статті алгоритми шукали підрядок, який дійсно є в тексті, та вигаданий підрядок.

| Файл           | Існуючий підрядок                  |
| -------------- | ---------------------------------- |
| `стаття_1.txt` | `алгоритми – це послідовність`     |
| `стаття_2.txt` | `метою даної роботи є дослідження` |

Вигаданий підрядок для обох статей:

```text
вигаданий_підрядок_якого_немає
```

Час виконання вимірювався за допомогою модуля `timeit`. Кожен алгоритм запускався 20 разів.

## Аналіз результатів

Для першої статті найменший сумарний час показав Boyer-Moore — `0.004417` секунди.

Для другої статті Boyer-Moore також був найшвидшим із результатом `0.004698` секунди.

Найбільша різниця між алгоритмами спостерігається під час пошуку вигаданого підрядка. Boyer-Moore може пропускати частини тексту завдяки таблиці зсувів, тому не перевіряє кожен символ послідовно.

KMP працював стабільно, але в проведених тестах поступився Boyer-Moore. Rabin-Karp показав найбільший час, оскільки під час пошуку додатково обчислює та порівнює хеші.

## Висновок

У проведеному порівнянні найкращий результат для обох статей показав алгоритм Boyer-Moore. Його загальний час становив `0.009115` секунди.

Отже, для використаних текстів і підрядків Boyer-Moore виявився найефективнішим алгоритмом. Водночас результат може залежати від довжини тексту, розміру підрядка та його розташування.
