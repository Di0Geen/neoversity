## Завдання 1. Обробка заявок за допомогою Queue

У файлі `task_1.py` реалізовано програму, яка імітує роботу сервісного центру.

Програма створює заявки, додає їх до черги, а потім послідовно обробляє у порядку надходження.

Для реалізації використано клас `Queue` з модуля `queue`.

Черга працює за принципом FIFO:

```text
First In — First Out
```

Це означає, що заявка, яка була додана першою, буде оброблена першою.

### Основні можливості програми

- створення нової заявки;
- автоматичне присвоєння унікального номера заявки;
- додавання заявки до черги;
- обробка заявки з початку черги;
- повідомлення, якщо черга порожня;
- робота через просте меню в терміналі.

### Запуск

```bash
python3 task_1.py
```

## Завдання 2. Перевірка паліндрома за допомогою deque

У файлі `task_2.py` реалізовано функцію, яка перевіряє, чи є рядок паліндромом.

Паліндром — це рядок, який читається однаково зліва направо і справа наліво.

Для перевірки використано `deque` з модуля `collections`.

Програма:

- переводить рядок у нижній регістр;
- прибирає пробіли;
- додає символи у двосторонню чергу;
- порівнює символи з початку та кінця черги;
- визначає, чи є рядок паліндромом.

### Приклади паліндромів

```text
Око
Радар
Кіт тік
```

### Запуск

```bash
python3 task_2.py
```
