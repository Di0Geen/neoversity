Python є популярною мовою програмування, яку використовують для веброзробки,
автоматизації, аналізу даних і створення серверних застосунків. Її синтаксис
досить зрозумілий, тому вона добре підходить для навчання.

Модуль Threading дає змогу одночасно працювати з кількома операціями введення
та виведення. Наприклад, різні потоки можуть читати окремі текстові файли.

Docker упаковує програму та її залежності в контейнер. Git допомагає зберігати
історію змін коду й працювати над проєктом разом з іншими розробниками.
