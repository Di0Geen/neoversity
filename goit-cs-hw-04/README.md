# Домашнє завдання goit-cs-hw-04

Домашня робота до модуля «Конкурентність та паралелізм».

## Опис завдання

Розроблено програму для паралельної обробки текстових файлів і пошуку заданих ключових слів.

Створено дві версії програми:

- багатопотокову — з використанням модуля `threading`;
- багатопроцесорну — з використанням модуля `multiprocessing`.

## Багатопотокова версія

Файл `goit_cs_hw_04_threading.py` розподіляє текстові файли між окремими потоками.

Кожен потік:

- отримує свою групу файлів;
- читає вміст файлів;
- шукає задані ключові слова;
- передає знайдені результати через `Queue`.

Після завершення потоків результати об'єднуються в один словник.

## Багатопроцесорна версія

Файл `goit_cs_hw_04_multiprocessing.py` розподіляє текстові файли між окремими процесами.

Кожен процес:

- обробляє свою групу файлів;
- шукає ключові слова;
- передає результат головному процесу через `multiprocessing.Queue`.

Для правильного запуску на macOS використовується перевірка:

```python
if __name__ == "__main__":
```

## Результат роботи

Обидві версії програми повертають словник, у якому:

- ключ — пошукове слово;
- значення — список шляхів до файлів, у яких знайдено це слово.

Результати виводяться в терміналі у вигляді таблиці з такими колонками:

- ключове слово;
- кількість знайдених файлів;
- шляхи до знайдених файлів.

Також програма вимірює та виводить час виконання кожної версії.

Передбачено обробку помилок читання файлів і роботи з файловою системою.

## Запуск проєкту

Додаткові бібліотеки встановлювати не потрібно. Програма використовує лише стандартні модулі Python.

Запустити багатопотокову версію:

```bash
python3 goit_cs_hw_04_threading.py
```

Запустити багатопроцесорну версію:

```bash
python3 goit_cs_hw_04_multiprocessing.py
```

Час виконання програм може відрізнятися. Для невеликої кількості файлів багатопроцесорна версія може працювати повільніше через додатковий час на створення процесів.
